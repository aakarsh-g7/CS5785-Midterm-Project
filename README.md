# CS 5785 midterm

Run the notebooks in a Python 3 Jupyter kernel with NumPy, pandas, SciPy, scikit-learn, Matplotlib, and RDKit. The main notebooks were verified with Python 3.14, scikit-learn 1.9.1, and RDKit 2026.9.1.

1. Open **Part 1/part1.ipynb** from the **Part 1** directory and run all cells. It generates the figures, the original reason labels used in Part 2, and the challenger submission. The challenger was scored at 0.89871 on the public leaderboard.
2. Open **Part 2/part2.ipynb** from the **Part 2** directory or the repo root and run all cells. It reproduces the Part 2 blend that scored 0.59100 on the public leaderboard and writes the validation, stopping-reason and calibration tables. **Part 2/part2_experiments.ipynb** contains the separate train-only experiments.
